# Architecture Decision Records

Records use a [MADR](https://adr.github.io/madr/)-derived format that compares options before stating the decision; see [template.md](template.md). Each new record lives at `NNNN-kebab-title/ADR.md`, numbered sequentially. Put diagrams and other static resources in the same directory and link to them relative to `ADR.md` (for example, `./topology.svg`). Existing flat `NNNN-kebab-title.md` records remain at their original paths and count toward numbering. A proposed record describes a decision under discussion, not an implemented contract. Add a linked row below only after authoring a record; link to `NNNN-kebab-title/ADR.md` for new records or the original flat path for legacy records.
