# Hypertextual

Hypertextual is an Obsidian/Google Docs/Notion replacement with a focus on extensible, agent-friendly markdown-based file format extensions that bring the convenience of "Agent artifacts" with the first-class editing support of conventional document editing tools

## Quick start

Install [Mise](https://mise.jdx.dev/getting-started.html), [Premise](https://github.com/cloudvoyant/premise#readme), and the [Tauri native prerequisites](https://v2.tauri.app/start/prerequisites/) for your operating system, then run:

```bash
mise trust
pm install
pm run hypertextual-desktop:dev
```
