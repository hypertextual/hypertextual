# Market Research

Hypertextual is a local-first Markdown workspace and knowledge base for technical writers and engineers. It stores articles and media as plain files on disk so that standard version control tools can track every change. This document compares alternatives in the local Markdown and knowledge management space.

## Alternatives

The table below compares local-first Markdown knowledge tools across core product features. OpenKnowledge provides an open-source editor with templates and collaboration. It supports agent integrations through AG-UI (Agent-User Interaction protocol, an event protocol for agent interfaces). It also connects to external coding agents through the Model Context Protocol (MCP, a standard interface for AI tool access). Obsidian provides a local Markdown editor with templates and paid sync or publish add-ons, while its core application remains closed source.

| Product | Editor | Templates | Collaboration | AG-UI / Agent Integrations | Open Source | Notes |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| [OpenKnowledge](https://openknowledge.ai/) | Yes | Yes | Yes | Yes (AG-UI, MCP, Skills Studio) | Yes | Local Markdown files, Git support, and native agent workflows |
| [Obsidian](https://obsidian.md/) | Yes | Yes | Paid add-on | Via community plugins | No | Local Markdown vault, plugin ecosystem, and canvas views |
